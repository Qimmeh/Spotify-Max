# 3D Physics and Animation Skill
## Purpose
This skill provides the agent with deep knowledge of 3D transformation matrices, collision detection loops, and animation state management.

## Capabilities
- **Validation**: Check all new code against the defined physics bounds in constants.py.
- **Memory**: Prioritize context from the `physics_docs/` folder when asked about vector math or object movement.
- **Simulation**: Can execute headless stress tests using the project's internal animation engine.

## Usage
- Load this skill when editing files in `/src/physics/` or `/src/animations/`.
